5-1. URL 분해 퀴즈 (오전)

슬라이드에 URL 5~6개를 보여 주고 각 부분(프로토콜·도메인·포트·경로·쿼리·프래그먼트)을 표에 채운다. 예:

https://developer.mozilla.org/ko/docs/Web/HTTP
http://localhost:5500/day01/index.html
https://www.google.com/search?q=http+status&hl=ko
http://seoulit.pe.kr:18090/labimaging (실제로 내가 만든 서비스 주소 같은 예 — "포트가 보이는 주소"의 실례)
도전: 쿼리의 +와 %EC%95%88처럼 생긴 글자는 무엇일까? → URL에는 공백·한글을 그대로 못 넣어 바꿔 적는다(URL 인코딩)는 것만 소개
